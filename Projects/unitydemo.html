Unity Turn-Based Tactics Game Demo

Fall 2026

GitHub link: nateyboy12/Unity-Turn-Based-Strategy-Demo

I started this demo to learn the basics of Unity and turn-based tactics at the same time. I wanted something small enough to finish, but fun and complete enough to learn how similar games actually work. It includes a turn system, cameras, a grid, units and their actions, pathfinding, enemy AI, interactables, level scripting, UI, and more.

The player moves units across a grid, spends actions, and fights enemies that can also take their own turns. Behind that is a pathfinding setup for efficient movement, cameras that follow the action, and scripted level moments plus interactable objects so a map can feel like a scene instead of just a board. The UI shows the turn flow, units' actions, and the coins collected through interacting with the barrels.

It is a learning project first, but it is also the kind of systems work I want to keep doing if I end up designing or programming games for a living. My potential next steps include:

  • Adding a main menu and a settings menu
  • Adding a more complex level scripting system
  • Modifying interactable objects to have more complex behaviors
  • Adding multi-floor levels
  • Adding unit/enemy classes with new abilities/weapons
